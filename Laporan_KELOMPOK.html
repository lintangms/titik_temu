1. PENJELASAN FITUR INDIVIDU MASING-MASING ANGGOTA

ANGGOTA 1: Lintang Arya Nugraha (NIM: 24050123001) — Modul Utama Kelola Data Barang

A. Peran Fitur dalam Aplikasi Secara Keseluruhan:
Modul Kelola Data Barang (/barang) merupakan jantung dan mesin utama (core hub) aplikasi TitikTemu. Modul ini menampung seluruh siklus data barang dari civitas akademika kampus, mengelola perubahan status barang (Hilang → Ditemukan → Sudah Dikembalikan), menyuplai metrik statistik ke dashboard secara realtime, dan menjadi data referensi pembuatan berita acara serah terima.

B. Alur Kerja Fitur (Frontend → Backend → Database):

[Frontend: Blade View & Modal Form] → (HTTP POST /barang) → [Backend: BarangController@store & Validasi] → [Database: Eloquent INSERT INTO barang]
  • Frontend (Tampilan): Pengguna membuka modal interaktif #modal-form untuk tambah/edit data, melihat seluruh detail barang pada #modal-detail, serta konfirmasi hapus melalui #modal-hapus-barang dengan tombol berikon SVG minimalis.
  • Proses Server (Backend): Dilindungi middleware autentikasi dan otorisasi role Satpam. Input divalidasi ketat (nama minimal 3 karakter, verifikasi kategori dan lokasi terdaftar, tanggal wajar 2000-sekarang, dan nomor HP valid). ID unik berformat BRG-001 di-generate secara otomatis.
  • Penyimpanan Database: Data disimpan ke tabel barang melalui Eloquent ORM dengan prepared statements sehingga terlindung dari SQL Injection.

2. PEMENUHAN PERSYARATAN TEKNIS & KEAMANAN

Kriteria Penerapan pada TitikTemu
Autentikasi & Role Registrasi pengguna dengan validasi duplikasi. Login/Logout dengan verifikasi hash bcrypt serta pemisahan role Satpam dan Mahasiswa.
Manajemen Profil Melihat data profil, mengubah nama/kontak, ganti password, serta fitur Hapus Akun Sendiri di zona bahaya dengan konfirmasi ketik "HAPUS".
Keamanan Akses (Anti-Bypass) Middleware otentikasi memblokir akses langsung URL tanpa login. Dilengkapi header Cache-Control: no-cache, no-store, must-revalidate dan event pageshow untuk memblokir tombol Back setelah logout.
Anti SQL Injection & XSS Menggunakan Eloquent ORM & PDO Prepared Statements. Seluruh output data dieksekusi melalui Blade sanitasi otomatis (anti-XSS).
Desain Responsif & Tema UB Menggunakan warna Biru Gelap Universitas Brawijaya (#003366), tombol aksi ikon SVG minimalis, dialog konfirmasi modal, dan layout adaptif desktop/mobile.
